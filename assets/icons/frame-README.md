# Scholarmate clean bookbinding border

The chosen bookbinding frame with all corner leaves and ornamental corner strokes removed. Retains leather shading, rounded corners and two fine gilt rules. Transparent center; separate reusable border, independent of website theme.

Includes frame.svg, transparent PNGs at 512/256/128/64/48/32px, CSS wrapper, and examples using unchanged approved shield and fork images. Use the separate SVG over future artwork. Example: <span class="scholarmate-icon"><img src="icon.webp" alt="Defense"></span>. Give decorative duplicates empty alt text and interactive controls their own accessible names and visible focus.

No new icon artwork was generated. This is an original vector border refinement.
