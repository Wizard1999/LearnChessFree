# Overlaps to resolve

Policy (Andrew, 28 October 2026): **nothing is taught twice. Lessons link to each other instead.** Where two lessons show the same position or teach the same skill at the same depth, one keeps it and the other links to it (or swaps in a different position that adds something new). The interlinking comes from the skill graph (prerequisites and each course lesson's `uses`) and is shown on every lesson page under "Connected lessons".

`tools/check_overlap.py` is the gate: it fails while any overlap exists, so new lessons cannot add more. Run it after every authoring batch. The list below is generated by the checker, not hand-written. Several entries are one famous position used for two different ideas and need a decision; most are the same exercise shown in a core lesson and a later one.

Resolution method per overlap: (1) keep the position in the lesson that teaches its idea best (usually the earlier, narrower one); (2) in the other lesson replace the step with a different verified position, or delete the step and add a card that links to the first lesson by name; (3) re-run `tools/validate_lessons.py` and the checker. Do this with agents after the usage reset, one batch of lessons per agent, with the checker as the acceptance test.
