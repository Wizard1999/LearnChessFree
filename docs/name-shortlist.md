# Name shortlist

Criteria from the design doctrine (`docs/design-doctrine-v1.md`): a welcoming public chess club with the atmosphere of a great tournament; serious but not stiff; one name that works as a wordmark with a single chess-derived detail; easy to say and spell; not a derivative of an existing chess brand. The product teaches by honest evidence and self-direction, and its tagline candidate is "Every position holds a possibility."

Evidence labels: **[V]** checked on 25 October 2026, **[I]** my judgement. Domain checks are RDAP lookups for .com, .net and .org: "no record" means nothing was registered at the time, not that it is reserved for us. **This is not a trademark search**; a real clearance (for example USPTO and UK IPO databases, and app stores) is separate work before launch.

| Name | Why it fits | Conflicts found | Domains [V] |
|---|---|---|---|
| **Long Diagonal** | The a1-h8 diagonal: the line that connects corner to corner, where a bishop sees the whole board. Suggests reach, vision and possibility, which is the tagline in two words. Wordmark: one clean diagonal stroke between or through the letters (a cut that is also the diagonal). | None found as a brand, app, school or club [V]. Used only as a chess term. | longdiagonal .com, .net, .org: no record |
| **Quiet Move** | The move that has no tactic and wins anyway. It is the project's own thesis (unlabelled positions, "no tactic here" items). Memorable and distinctive. | No product of that name found [V], but "quiet moves" is widely used as a course and book title. Risk that it reads as passive and clashes with the doctrine's call for drama at thresholds [I]. | quietmove .net, .org: no record; .com taken |
| **Luft** | "Breathing room": the first defensive lesson, and a promise to the learner. One short word, strong wordmark. | No chess product found [V]. A very common word and surname, so hard to own and hard to search for [I]. | luft .com/.net/.org taken; playluft no record |
| Open File | Open to everyone, free; a file with no pawns is a highway for a rook. | **Rejected.** "OpenFile Chess" already exists: an iOS spaced-repetition tactics app, the same niche [V]. | taken |
| Others considered | Tabiya (standard opening position; obscure), Key Square, Rank and File, Square One, Outpost, Candidate | Most have taken domains or crowded brand space [V: domains]; "Candidates" is a famous tournament. | mostly taken |

## Recommendation

**Long Diagonal.** It is the only candidate that is clear on every check: meaningful for the project, welcoming without explanation (a diagonal is something anyone can see), distinctive in the chess space, and available as a complete .com/.net/.org set. Fallback: **Quiet Move**, if you prefer a name that says what makes the method different.

Pronunciation and spelling are plain. Short form for tight spaces: "Diagonal" (used only in the wordmark's compact version). The repository can stay `LearnChessFree`: that is a description, not a brand.

## What changes when a name is chosen

- `app/src/brand.ts` holds the name; `index.html` title and `manifest.webmanifest` need the same edit (static files).
- The wordmark exploration in the design plan (step 7) begins: test at favicon size, in one colour, and with the name removed.
- Domain registration, trademark clearance and the GitHub repository name are your decisions (question Q4).
