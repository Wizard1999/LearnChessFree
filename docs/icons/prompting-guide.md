# Producing another icon

## Start with the current references

Read design-doctrine.md and review-status.md. Attach one approved rendering reference and, if needed, one subject-specific reference. Name their roles explicitly. A reference for material painting is not a request to depict its object, colors, damages or silhouette. Keep reference copies with the collection.

The exact historical prompts are in manifest.json. Many contain superseded fantasy language. They are provenance, not the current template. The current doctrine below takes precedence.

## Current generation template

> Create one square illustrated icon for Scholarmate, a present-day distinguished learning academy with history, culture, curiosity and adventure. Image 1 is only the approved painted rendering reference; do not reproduce its subject or colors.
>
> Subject: [one recognizable physical object/action]. Immediate impression: [plain idea]. Essential geometry: [the silhouette or relationship that must survive reduction]. Materials and colors: [subject-specific choices].
>
> Rendering: warm naturalistic hand-painted illustration with lively, carefully designed color shapes and confident drawing. Believable volume; broad readable value masses; restrained fine material details upon closer inspection. Match the reference's balance. No photographic product rendering, slick plastic gloss, dense microtexture, blurred photo effect, coarse impasto or chiseled facets. Do not flatten it into a generic cartoon or a featureless symbol.
>
> Composition: subject fills roughly 80–85 percent of the square; allow room for the separate border. One main subject; only essential supporting shapes. Legible at 32px. Black empty space around the subject, no floor or environment.
>
> Atmosphere: [none / a faint diffuse patch behind selected dark areas / natural emitted light for this genuinely luminous subject]. No contour-following glow or neon outline. Object colors are independent of website themes.
>
> No embedded frame, lettering, watermark, UI, logos or chess imagery except for dedicated chess-piece portraits.

Do not overload every prompt with distress. Choose the few details that characterize that particular material and use. For food, request soft painted shading and limited broad highlights; avoid wet photorealistic sheen.

## Revision template

> Edit the target reference. Change only [one specific thing]. Preserve [silhouette, geometry, colors, drawing, texture, lighting, framing as applicable]. The approved result must still read at 32px. Do not reinterpret unaffected parts.

For a near-approved asset, edit it rather than generate from scratch. For the approved pin, use strict background replacement only if ever needed; do not redraw the cloth. A prompt promising unchanged pixels does not prove pixel identity: inspect the result.

## Failure-specific corrections

| Failure | Better correction |
|---|---|
| Beautiful but unreadable small | Change silhouette/value grouping; reduce secondary mechanisms |
| Photo-like bulb or slick food | Restore painted color shapes and drawn form; reduce specular/microdetail |
| Lifeless featureless surface | Add a few deliberate material details, not global noise |
| Wrong meaning | Replace the metaphor before polishing rendering |
| Neon silhouette | Remove outline; use faint atmosphere behind only if needed |
| Brand/game association | Change framing/subject language; retain Scholarmate's independent identity |

## Reproduction limits

Image generation can vary across runs and model versions. Approved references, exact prompts, explicit invariants, native masters and review history are the reliable handoff. Preserve all of them. Do not claim an unreviewed candidate is a faithful continuation merely because its prompt used the same words.
