# Study scripts for L-HI-ENGINES-HUMANS-4 (30 Oct 2026)

Reproduces the numbers on the "how club players lose" cards. Source: `library/data/lichess_db_standard_rated_2013-01.pgn.zst` (online games of January 2013, not master chess). Scripts were run from a scratch folder; paths inside point there (edit `SP`). Order: `scan.py` (hook counts, sample of games) -> `an.py` (engine pass over the sample), `cls.py` and `fin.py` (classification and totals). Engine: Stockfish 19 lite, depth 8 per position for the blunder study (noisy, evidence not proof), depth 14 to 16 for positions shown in the lesson. A flagged move = the mover's evaluation falls by 200 centipawns or more and was not already below -500. Game counts: 300 + 300 games (both players 1000-1499, slow and fast time controls), 142 games (both 2000+). `pop.py` and `pop2.py` count the move chosen after common opening prefixes by rating band and measure how much the most popular move loses.
