Environment used for the checks in this folder (2026-10-24)
- python-chess 1.11.2 (pip, venv)         - Python 3.11.3, Node v24.18.0
- Stockfish 19 Lite WASM, single thread, Hash 16 MB, NO tablebases  (npm stockfish@19.0.1; registry licence field: GPL-3.0)
- Lichess tablebase API (tablebase.lichess.ovh/standard), queried with curl; JSON saved as tb_*.json
- 'category' on each move = result for the side to move AFTER that move (win => the mover's move loses).
- Search limits: l2_l3_engine.txt MultiPV=all legal moves, depth 40 (root + selected nodes); l2_deep.txt single-PV, depth 36.
- Mate scores / large cp are engine evidence, not proofs: 8-man pawn endings are outside 7-man tablebases.
